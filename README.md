# ShenmoOS · 沈秣小系统

一个真正原生的 Android App 新仓库。

## 当前状态

当前版本是第一盏灯：最小 Kotlin 原生 Android 工程 + GitHub Actions 云端打包。

它的目标是先验证：
- 仓库能被 GitHub Actions 拉取
- Android SDK 和 Gradle 能正常构建
- 能产出 `app-debug.apk`
- 后续可以继续扩展桌面、聊天、记账、督学、语音、设备和健康模块

## 下一阶段

- 类手机桌面
- 聊天窗口
- 本地记忆核心
- 支付宝账单导入
- 督学模式
- 语音陪伴
- 蓝牙设备控制
